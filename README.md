# AutoBrush
This plugin helps you to not suffer anymore with the texture paint brush when you zoom or unzoom
This plugin was made with the help of AI
How to install:
Go on preference > Addons > Install from disk > select the .py and you are done
Select a focus object you want, and always enable Apply Automacly

TEST WITH BLENDER 5.1.1 NO IDEA IF IT WORKS ON OTHER VERSION TOO
